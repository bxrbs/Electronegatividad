# Electronegatividad
Proyecto para calcular tipos de enlaces químicos dados dos elementos de la tabla periódica.
El usuario elige con que elementos quiere trabajar y al ejecutar el programa, este hace una búsqueda dentro de su base de datos para dar al usuario cuál es la electronegatividad de dichos elementos asi como el cálculo del enlace covalente polar, no polar, iónico o puro, o en caso de que suceda, si uno o ambos elementos no tienen electronegatividad definida.
